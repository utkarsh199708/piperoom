# Security policy

Piperoom connects to production data pipelines and can run approved fixes, so we take reports seriously.

## Reporting a vulnerability

Please do not report security problems in a public issue, pull request or discussion.

Use **Report a vulnerability** on the repository's
[Security tab](https://github.com/utkarsh199708/piperoom/security). If that option is not available, open
an issue that asks for a private contact and leave out all details of the problem.

Please include:

- the affected version or commit
- steps to reproduce the problem
- the impact you expect

## Supported versions

Piperoom has no versioned releases yet. Security fixes go to `main`.

## Disclosure

Please give us a reasonable chance to fix the problem before you publish details. We will credit you
in the fix unless you ask us not to.
