## Medium

**Data correctness / diagnosis**
- Transactional topics (EOS Debezium): `TopicOffsets`/`kafka_topic_offsets` hang to timeout; `FindByKey` for an absent key times out instead of "not found" — `internal/clients/kafka/kafka.go:303-438` (no `KeepControlRecords`).
- `FindByKey` returns on first fetch with a match → can miss the newest occurrence (latest update/tombstone) — `kafka.go:347`.
- `schema_registry_diff` with a raw `schema` diffs in reverse and ignores `from_version` — `internal/tools/kafkatools/registry_tools.go:204-224`.
- JSON Schema subjects always diff as "no field changes"; Protobuf errors — `registry_tools.go:270-320`.
- `pg_recent_ddl` misses column renames, index/comment DDL, and mixed-case tables (exact `object_identity` match) — `internal/tools/dbtools/pg.go`.
- `timestamptz 'infinity'` → `"1"`; jsonb big numbers lose precision — `internal/clients/pgconv/pgconv.go:22-67`.
- Connect down → topic node named after the table instead of `<topic_prefix>.<table>` — `internal/topology/builder.go:592-597`.
- Missing sink table / CDC topic / consumer group reported as `unreachable`/`UNKNOWN`, not "not found" (PG warehouse client doesn't map 42P01; `GroupLag` doesn't wrap `GROUP_ID_NOT_FOUND`) — `internal/clients/warehouse/warehouse.go:69,93`, `kafka.go:250-262`.
- `owners.Load` accepts duplicate list entries (duplicate graph node IDs) and malformed names — `internal/owners/owners.go:150-178`.

**Security / data exposure**
- Trace leaves pipeline scope when Connect is unreachable → row-existence oracle on any readable table — `internal/topology/trace.go:72-81`.
- Read-only is only a session GUC on a superuser role; a planted view function flipped it off for the pooled connection — `postgres.go:31`. Use read-only `BeginTx` + SELECT-only role.
- `pg_row` accepts any column as `pk_column` (incl. `ctid`) → existence oracle — `dbtools/pg.go`.
- PII (SSN, card, phone) in Connect traces / error text reaches the model and room log unmasked; `connect_status` traces aren't redacted at all — `internal/tools/kafkatools/connect_tools.go:118-131`, `internal/redact`. `textnorm` already masks these.
- Alert titles and comment/steer text are never redacted (DSN password reached the model) — `internal/agent/prompt.go`.
- Signed alert replay within the window (±5 min; bearer sources forever) floods a room toward the 20k-event cap — `internal/alertin/verify.go:263-289`.
- No rate limit on alert-opened rooms; agent queue unbounded — `internal/httpapi/alerts.go:30-81`.

**Robustness**
- Multi-replica: comments, steers and an approval appended after `room.closed` (store has no closed guard) — `service_steer.go:113`, `service_proposals.go:272`.
- jsonb number amplification: `1e308` tokens bypass the byte cap 52× (1 MB → 54 MB event) — `internal/room/jsonb_guard.go:45-55`.
- Hand-off returns 500 when the model is unavailable; no fallback summary, driver can't move — `internal/room/service_handoff.go:82-85`.
- Connect status body > 4 MiB fails hard instead of truncating — `internal/clients/connect/connect.go:192`.
- Watcher tick can take 3×CheckTimeout (sequential Status → Config → DLQ), doubling time-to-fire — `internal/watch/observe.go`.
- franz-go ignores ctx deadline while dialing a hung broker (10 s) — affects `dlq_peek` and tools.

**UI**
- WS down → room shows "Proposals 0 / agent not started / no activity" despite snapshot data; no clear banner.
- `SteerBox` clears text before the request returns; a failed steer loses it — `web/src/components/SteerBox.tsx:101-105`.
- Mobile: pending approval card not first; 20 controls under 44 px; rooms table truncates titles at 1440 px.

## Low (abridged)

## Test-infra gap (fix first — it hides bugs)
`internal/testenv/testenv.go:23-37` skips **every** integration test when Connect is down, including
Postgres-, Kafka- and warehouse-only tests. With Connect absent, `clients/postgres` (13 tests),
warehouse and most Kafka integration tests silently skip; unit coverage there is 5.6%, 10.5%.
Gate per dependency instead.

## Scenario gaps (QA7 domain review)
No scenario has as root cause: idle-in-transaction holding `restart_lsn`; missing Debezium heartbeat;
missing REPLICA IDENTITY / TOAST unavailable value; `RecordTooLargeException`; at-least-once
duplicates breaking MERGE; partition increase breaking key order; warehouse load failures
(credentials, suspended warehouse); lost Connect offsets topic; `wal_status=lost`; slots dropped by
major upgrade; `decimal.handling.mode`; clock-skew false staleness. DLQ poison pill is heldout-only.
