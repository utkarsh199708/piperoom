## 5. Gates on every X and AU PR (from the epics)

- `gofmt`, `go vet ./...`, `go build ./...`, `go test ./...` on Windows without Docker; web lint, build, vitest.
- Every new watcher signal or agent behaviour has a `devctl break` and a recorded scenario; `evalrun -validate`
  passes and the CDC pass rate does not drop against `evals/baseline/default.json`.
- No write path without `Preview` and `Verify`; AU never relaxes the hard rules in KAN-461.
- Every new reader has a row in `docs/pilot/data-handling.md` in the same PR.
- Owned folders only; contract changes only in the `-0` tasks; PRs under 600 changed lines.
